# Memory Universe 项目实施计划

## 目标

交付一个真实可运行的全栈项目：Vue 3 前端（3D 星空宇宙、时间轴、留言、毕业结尾、管理后台）+ Spring Boot 后端（JWT 鉴权、照片存储、内容管理）+ MySQL 8 + MinIO。

## 阶段划分

### P1 工程基座与核心链路（本次完成）

**工程**

- 前后端目录初始化、Vite / Maven 构建通过。
- 设计令牌、全局样式、路由、布局、Pinia、Axios 封装。
- AGENTS.md、README、docker-compose、实施计划。

**后端**

- 统一响应 / 全局异常 / 参数校验。
- Spring Security + JWT（无状态、角色校验、401/403 JSON）。
- MySQL 表结构（user / category / photo / message / music）。
- MinIO 存储抽象（MinIO + 本地双实现）、原图 + 缩略图生成。
- 管理员账号启动引导（BCrypt，环境变量注入）。
- 公开照片 / 分类 API；后台照片 / 分类 API。
- H2 测试环境 + MockMvc 接口测试。

**前端**

- 深空视觉首页（前置 3D 星空 + 传送门背景，真实分类与照片数据）。
- 照片宇宙页：Three.js 引擎（星空、星云、传送门、照片星环、OrbitControls、射线拾取、随机回忆、详情弹窗）。
- 后台登录、后台布局、路由守卫。
- 时间轴 / 留言 / 结尾 / 后台其余页面的视觉骨架（明确标注建设中）。

**验收标准**

- `mvn test` 全绿，`npm run build` 通过。
- 未登录访问 `/api/admin/**` 返回 401；登录后可访问。
- 上传图片后能在 MinIO（或本地存储）生成原图与缩略图，公开接口可读到。
- 3D 场景切换路由后无内存泄漏（dispose 被调用）。

### P2 3D 宇宙深化

- 照片分环 / 星座布局、远近 LOD、实例化星星。
- 点击相机飞行、照片聚焦、景深式模糊、后处理（Bloom）。
- 随机回忆动效、移动端降级（低粒子数 / 关闭后处理）。
- 详情页与 3D 场景联动、键盘可达性。

### P3 后台资产运营

- 照片管理：批量拖拽上传、进度、分类、标题、时间、可见性、删除。
- 分类管理：增删改查、排序、封面。
- 上传队列与失败重试、图片裁剪预览。
- 仪表盘真实统计。

### P4 时光轴与留言星球

- 时间轴按年份 / 月份聚合、筛选、滚动叙事与 GSAP 编排。
- 留言：提交（待审核）、审核通过展示、点赞、球面分布。
- 敏感词与频率限制。

### P5 音乐与毕业结尾

- 背景音乐播放器（全局、淡入淡出、切换、移动端权限处理）。
- 毕业结尾：镜头推进、星球汇聚、字幕序列、分享海报。

### P6 质量与交付

- 前后端集成测试、E2E 关键路径。
- 性能预算（首屏、3D FPS、内存）、可访问性、SEO。
- Docker 镜像、Nginx、生产环境变量与备份策略。

## 技术决策

1. **存储抽象**：`StorageService` 接口，MinIO 为默认实现，本地实现用于测试 / 无 MinIO 场景；业务层不感知实现。
2. **缩略图**：服务端 Thumbnailator 生成 720px 以内 JPEG，原图保留原始格式。
3. **鉴权**：JWT 无状态，角色写入 claim；后台接口在过滤器链统一拦截，前端守卫仅做体验层控制。
4. **3D 性能**：星空使用 `Points` + 顶点色；照片使用共享几何体 + 独立纹理；像素比上限 2；移动端减少粒子。
5. **配置安全**：开发默认配置仅用于本地；生产 profile 只读环境变量。
